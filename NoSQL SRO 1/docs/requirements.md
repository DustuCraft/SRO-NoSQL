# Требования и Access Patterns — Каталог электроники

## Функциональные требования
| ID | Требование |
|----|-----------|
| FR-1 | Создание, чтение, изменение и удаление карточки товара (CRUD). |
| FR-2 | Хранение категорий и привязка товара к категории. |
| FR-3 | Фильтрация товаров по категории и диапазону цены с сортировкой. |
| FR-4 | Фильтрация по характеристикам (RAM, бренд и др.), разным для разных категорий. |
| FR-5 | Агрегация: средняя цена по категориям, статистика по брендам, ценовые сегменты. |
| FR-6 | Полнотекстовый поиск по названию и бренду. |
| FR-7 | Контроль остатков (список товаров с низким остатком). |

## Нефункциональные требования
| ID | Требование |
|----|-----------|
| NFR-1 | Производительность: фильтр по категории и цене на 100 000 товаров — не более 50 мс (индекс вместо COLLSCAN). |
| NFR-2 | Гибкость схемы: новые характеристики добавляются без миграции. |
| NFR-3 | Целостность: уникальность SKU гарантируется индексом. |
| NFR-4 | Воспроизводимость: запуск одной командой через docker compose, без секретов в репозитории. |

## Access Patterns
| ID | Паттерн | Приоритет | Ожидаемый результат | Запрос / индекс |
|----|---------|-----------|---------------------|-----------------|
| AP-1 | Карточка товара по SKU | Высокий | 1 документ, IXSCAN | Q1, `uq_sku` |
| AP-2 | Список товаров категории (новые первыми) | Высокий | до 10 карточек | Q2, `ix_category_price` |
| AP-3 | Фильтр по цене в категории, сортировка по цене | Высокий | список без SORT-стадии в памяти | Q3, `ix_category_price` |
| AP-4 | Фильтр по характеристикам (RAM, цена, бренд) | Высокий | подходящие ноутбуки | Q4, `ix_category_ram` |
| AP-5 | Средняя цена по категориям | Средний | таблица категория → avg | Q5, $group |
| AP-6 | Поиск по тексту | Средний | результаты по релевантности | Q6, `tx_name_brand` |
| AP-7 | Топ по рейтингу в категории | Средний | топ-N | Q7, `ix_category_rating` |
| AP-8 | Товары с низким остатком | Низкий | список для закупки | Q8 |
| AP-9 | Статистика цен по брендам | Низкий | min/avg/max, рейтинг | Q9, $group |
| AP-10 | Ценовые сегменты | Низкий | распределение по корзинам | Q10, $bucket + $lookup |
